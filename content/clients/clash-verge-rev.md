## 核心步骤摘要

Clash Verge Rev 是目前 PC 与 Mac 平台最推荐的开源代理工具。**使用流程仅需四步：GitHub官方仓库下载安装 -> 机场后台复制Clash订阅链接 -> 客户端订阅管理粘贴拉取 -> 选中节点并开启系统代理**。

## 客户端下载前准备

- **从可信渠道下载：** 务必访问 GitHub 官方仓库 Release 页面下载安装包，Windows用户下载 `.exe` 或绿色版，Mac用户根据芯片架构选择 `x64` 或 `aarch64`（M系列芯片）；
- **避开仿冒钓鱼网站：** 搜索引擎中存在大量竞价排名的山寨下载站，绝不要下载携带挖矿或木马的非官方打包版。

## 订阅导入与配置步骤

1. **获取订阅链接：** 登录你的机场后台（如梯子云、暮光加速等），找到“复制Clash订阅”或“一键导入Clash”；
2. **新建订阅配置：** 打开 Clash Verge Rev，在左侧导航点击【订阅（Profiles）】；
3. **粘贴并导入：** 在上方输入框粘贴刚复制的订阅 URL，点击右侧【保存并导入】；
4. **选择节点并启动：** 进入【代理（Proxies）】界面，确保模式选择【Rule（规则模式）】，选中一个绿色低延迟节点；
5. **开启系统代理：** 在【设置】或右下角系统托盘图标右键勾选【系统代理（System Proxy）】。

## 常见排障方法

- **导入提示 Connect Timeout：** 尝试断开本地杀毒软件防火墙，或开启手机热点尝试重新更新；
- **国内网页打不开：** 检查代理模式是否误设成了 Global（全局），切回 Rule（规则）即可恢复国内直连。

## 常见疑问解答

**Q: 什么是 TUN 模式？平时需要开吗？**  
A: TUN 模式通过创建虚拟网卡接管系统所有进程（包括不走系统代理的命令行或外服游戏）。普通网页浏览不需开启，玩外服游戏或跑代码时建议开启。

**Q: 软件关闭后电脑彻底断网怎么修复？**  
A: 这是由于系统代理开关未能正常复位所致，进入 Windows 设置 -> 网络和 Internet -> 代理，关闭“使用代理服务器”即可恢复。
