# 机场客户端有哪些？Windows/Mac/iOS/Android 全平台客户端对比与选择

购买了机场订阅之后，我们需要在电脑或手机上安装**代理客户端软件**，才能将订阅链接转化为可用的网络连接。

面对网络上众多的客户端名称（Clash、Clash Verge Rev、Shadowrocket、v2rayN、Sing-box、Surge…），新手往往不知道该下载哪一个。**各平台最好用、最稳定的客户端是哪些？** 本文为你一网打尽。

---

## 一、全平台主流机场客户端全景速查表

| 操作系统 | 首选推荐客户端 | 备选推荐客户端 | 核心优势与特点 |
| :--- | :--- | :--- | :--- |
| **Windows 电脑** | **Clash Verge Rev** | v2rayN / Sing-box | 中文界面现代化，内置 Mihomo 内核，支持 TUN 模式 |
| **macOS 苹果电脑** | **Clash Verge Rev** | Sing-box / Surge | 完美适配 M1/M2/M3/M4 芯片，分流规则成熟 |
| **iOS / iPadOS** | **Shadowrocket（小火箭）** | Sing-box / Loon | 操作极简，耗电低，支持扫码与一键导入订阅 |
| **Android 安卓手机** | **Clash Meta for Android** | v2rayNG / FlClash | 规则分流强大，支持绕过大陆应用，后台保活好 |

## 二、各主力客户端深度特点解析

### 1. Clash Verge Rev（电脑端首选王牌）
- **适用系统**：Windows / macOS / Linux
- **核心特点**：
  - 基于 Rust + Tauri 开发，界面美观轻量，内存占用小；
  - 内置功能强大的 Mihomo 内核，完美支持各类复杂分流规则；
  - 一键开启 Service Mode（服务模式）与 TUN 虚拟网卡接管。
- **配置教程**：[机场订阅怎么导入 Clash Verge 完整教程](/tutorials/clash-verge-tutorial/)。

---

### 2. Shadowrocket 小火箭（iOS 苹果生态首选）
- **适用系统**：iPhone / iPad / Apple Silicon Mac
- **核心特点**：
  - 界面简洁直观，新手上手难度最低；
  - 支持一键唤醒导入与二维码扫描导入订阅；
  - 路由规则清晰，后台保活出色且省电。
- **配置教程**：[Shadowrocket 小火箭一键订阅导入指南](/tutorials/shadowrocket-import-subscription/)。

---

### 3. v2rayN（Windows 经典老牌工具）
- **适用系统**：Windows
- **核心特点**：
  - 架构成熟，支持 Xray 与 Sing-box 双内核；
  - 节点参数显示详尽，适合喜欢查看具体路由日志的进阶用户；
  - 界面相对传统朴素。
- **配置指南**：[Windows 机场使用教程](/clients/windows/)。

---

### 4. Clash Meta / FlClash（安卓系统主力）
- **适用系统**：Android 安卓手机与平板
- **核心特点**：
  - 完美支持分应用代理（可单独设置仅国外 APP 走代理，微信/淘宝直连）；
  - 适配各种国产安卓系统（MIUI/HyperOS、OriginOS、ColorOS 等）。
- **配置指南**：[安卓机场使用教程](/clients/android/)。

## 三、新手选择客户端的 3 个建议

1. **电脑端新手闭眼选 Clash Verge Rev**：告别已经停止维护的老旧 CFW，Verge Rev 维护活跃、更新频繁。
2. **苹果手机准备海外 ID 下载小火箭**：小火箭仅需几美元买断，终身可用，省心程度远超其他工具。详见 [iPhone 小火箭配置教程](/clients/iphone/)。
3. **善用客户端的规则分流（Rule）**：所有客户端均建议保持在“规则/配置”模式，确保国内流量走本地网络。

## 四、本篇常见问题 (Q&A)

### Q1：客户端软件本身需要花钱买吗？
**答**：电脑端（Clash Verge Rev、v2rayN）和安卓端（Clash Meta）全部是开源免费的；iOS 上的 Shadowrocket 在海外 App Store 售价约 $2.99（一次买断终生使用）。

### Q2：客户端安装后就能直接上网吗？
**答**：不能。客户端只是一个空壳工具，必须填入购买的机场订阅链接拉取节点后才能上网。选购参考 [2026 机场订阅推荐：新手怎么选](/recommend/best-airport-subscriptions/)。

### Q3：同一条订阅链接可以在不同客户端上同时使用吗？
**答**：可以。比如电脑用 Clash Verge，手机用 Shadowrocket，填入同一条订阅链接即可。详见 [机场订阅地址怎么使用](/guide/how-to-use-subscription-url/)。
