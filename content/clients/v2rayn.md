## 核心步骤摘要

v2rayN 是 Windows 平台经典且占用内存极低的代理客户端，对新协议（如 VLESS Reality）支持最全面。**核心操作：下载解压 -> 订阅分组添加链接 -> 更新订阅 -> 选中活动服务器并开启自动配置系统代理**。

## 下载安装准备

- 前往 GitHub 官方仓库下载包含 Core 核心的完整发布包（如 `v2rayN-with-Core.zip`）；
- 解压至无中文、无空格的纯英文路径（如 `D:\v2rayN`）；
- 双击运行 `v2rayN.exe`，若提示缺少 .NET 运行时，根据提示点击跳转微软官网安装运行库。

## 订阅添加与节点选择

1. **添加订阅分组：** 顶部菜单点击【订阅分组】 -> 【订阅分组设置】；
2. **粘贴链接：** 点击左下角【添加】，在“可选地址（url）”处粘贴机场订阅，别名填写机场名称，点击【确定】；
3. **拉取节点：** 顶部菜单点击【订阅分组】 -> 【更新全部订阅（不通过代理）】；
4. **设为活动节点：** 节点列表加载后，鼠标点击选中一个低延迟节点，按回车键（Enter）设为活动服务器。

## 开启系统代理与路由

- 在主窗口底部将【系统代理】切换为【自动配置系统代理】（系统托盘小图标变红）；
- 将【路由】切换为【绕过大陆（whitelist/bypass CN）】，实现智能分流。

## 常见疑问解答

**Q: 托盘图标变红了但依然打不开 Google 怎么排查？**  
A: 先按 Ctrl+A 全选节点后按 Ctrl+R 进行延迟测试，查看节点是否有有效毫秒数；检查 Windows 电脑系统时间是否自动同步。

**Q: 怎样让浏览器以外的应用也走代理？**  
A: 在主界面下方启用 TUN 模式开关，即可接管全局网络流量。
