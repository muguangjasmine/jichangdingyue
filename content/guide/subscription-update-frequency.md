很多刚刚接触机场订阅的新手，往往对**“更新订阅”**的频率感到困惑：**需要每次开机都更新一次吗？多久不更新会导致节点失效？频繁更新会不会影响账号？**

本文将为你讲透机场订阅的更新机制，并教你如何在各大客户端中优雅地配置自动更新。

---

## 一、为什么需要“更新订阅”？

**更新订阅**，本质上是你的客户端向机场订阅服务器发起一次数据请求，重新拉取一份最新的节点配置列表。

需要更新订阅的典型场景包括：
1. **服务商更换了部分节点服务器的入口 IP 或端口**；
2. **服务商新增或删除了某些地区的节点**；
3. **敏感时期或网络维护后线路重新部署**。

---

## 二、机场订阅的最佳更新频率推荐

| 使用状态 | 推荐更新频率 | 操作建议 |
| :--- | :--- | :--- |
| **日常正常使用** | **无需频繁手动更新** | 当前连接的节点流畅顺畅，保持现状即可 |
| **推荐后台自动更新** | **每 24 小时（1440 分钟）一次** | 在客户端设置中开启定时拉取，后台静默完成 |
| **突发故障 / 节点变红** | **立即手动更新一次** | 先对时、查流量，然后手动点击更新拉取新 IP |
| **收到官方维护公告** | **维护完成后手动更新一次** | 服务商线路迁移完成后同步最新配置 |

> [!WARNING]
> **切勿设置过于频繁的自动更新**（例如每 5 分钟更新一次）。高频请求不仅浪费服务器资源，还容易触发机场防火墙的 API 防刷风控，导致你的 IP 被临时封禁。

## 三、主流客户端配置自动更新图文方法

### 1. Clash Verge Rev 设置自动更新
1. 进入左侧 **“订阅（Profiles）”** 界面。
2. 找到你的订阅卡片，鼠标右键点击并选择 **“编辑 / Edit”**。
3. 在弹出窗口中，将 **“更新间隔（Interval）”** 设置为 **1440**（即 24 小时）。
4. 点击保存，软件便会在后台每天自动拉取一次。详见 [Clash Verge 使用教程](/tutorials/clash-verge-tutorial/)。

### 2. Shadowrocket 小火箭设置自动更新
1. 点击底部 **“设置” -> “订阅”**。
2. 打开 **“打开时更新”** 开关（每次启动 APP 自动刷新）。
3. 打开 **“自动后台更新”** 开关。详见 [Shadowrocket 小火箭导入教程](/tutorials/shadowrocket-import-subscription/)。

## 四、本篇常见问题 (Q&A)

### Q1：长时间不更新订阅，节点会彻底失效吗？
**答**：只要服务器的底层 IP 没有被防火墙封锁或更换，几个月不更新订阅也能正常上网。
