01 机场订阅基础概念

Q1 机场订阅是什么意思？和普通VPN有什么区别？

机场订阅是指通过一条专属的URL链接，将服务商部署在全球的代理节点信息（包括服务器地址、端口、加密协议、密码等）一键同步到你的客户端软件中。普通传统VPN通常采用全局强加密隧道，容易受到网络特征识别导致断流，且无法区分国内外流量；而基于现代代理协议（如 Shadowsocks、VLESS、Trojan 等）的机场订阅支持按规则智能分流，国内网站直接走本地宽带，海外网站才走代理，日常打开网页更快且更灵活。

具体步骤 / 排查方法：
  1. 分流机制：国内流量（如百度、淘宝、微信）直连不走代理，海外流量走节点。
  2. 订阅同步：购买套餐后获取一条订阅链接，填入客户端即可自动获取所有节点列表。
  3. 节点更新：当服务商调整服务器或维护时，只需在客户端刷新订阅即可获取最新节点。

Q2 机场订阅链接长什么样？为什么不能直接在浏览器里打开？

机场订阅链接通常是一个以 https 开头的网址（如包含 token 或 api 参数的专用链接）。它本质上是提供给 Clash、Shadowrocket 等客户端解析的节点配置文件或 base64 编码数据。直接在普通浏览器中打开，往往只会显示一长串看似乱码的代码、字符或直接提示下载配置文件，这是完全正常的，只需将该链接完整复制并粘贴进代理客户端的订阅管理栏中即可正常拉取节点。

具体步骤 / 排查方法：
  1. 认清格式：订阅链接是给客户端读取的专用数据接口，非普通展示网页。
  2. 正确使用：在机场用户中心点击‘复制订阅链接’，切勿在聊天软件中多次转发避免截断字符。
  3. 填入客户端：打开 Clash Verge 或小火箭等软件，在‘订阅/配置’界面粘贴并保存下载。

Q3 机场订阅地址怎么使用？从复制到上网一共分几步？

使用机场订阅地址非常简单，整个流程只需四步：第一步，在机场官网用户中心找到‘快捷导入’或‘复制订阅链接’；第二步，在手机或电脑上打开对应代理客户端；第三步，将链接粘贴至客户端的配置添加栏并点击下载/更新；第四步，在节点列表中选择一个延迟较低的节点（如香港或日本），并开启客户端的‘系统代理’或‘连接开关’。

具体步骤 / 排查方法：
  1. 第一步：在机场后台复制对应客户端格式的订阅地址。
  2. 第二步：在客户端（如 Clash Verge Rev、Shadowrocket）中导入该链接。
  3. 第三步：成功拉取节点列表后，点击节点选择延迟较优的线路。
  4. 第四步：启动系统代理或开启全局路由规则即可顺畅上网。

Q4 什么是机场节点？香港、日本、新加坡、美国节点有什么区别？

机场节点就是部署在世界各地的代理服务器入口。不同地区的节点主要在物理延迟和访问范围上有所不同：香港和台湾节点物理距离最近，网页加载最快、延迟最低；日本和新加坡节点综合素质极高，网络带宽充裕且适合主流海外服务；美国节点物理距离较远，延迟相对稍高，但对于仅对北美开放的特殊海外站点最为适用。

具体步骤 / 排查方法：
  1. 日常网页与低延迟：优先选用香港、日本或新加坡节点。
  2. 北美特定服务：优先选用美国西海岸节点。
  3. 分流选择：建议客户端保持‘规则模式（Rule）’，让客户端按预设规则自动匹配。

Q5 机场订阅多久需要更新一次？需要每天手动更新吗？

正常情况下不需要每天手动更新。只要当前选择的节点连接顺畅、速度满意，保持现状使用即可。建议在遇到节点大面积变红超时、机场在公告群中发布了线路迁移通知、或者间隔 1-2 周时，在客户端中手动点击一次‘更新订阅’以同步最新的服务器地址和可用节点。

具体步骤 / 排查方法：
  1. 日常使用：无需频繁手动刷新，避免请求过于频繁触发机场 API 限制。
  2. 自动更新：可在客户端（如 Clash Verge）设置定时更新（如每 24 小时自动拉取一次）。
  3. 遇障排查：当节点全部连接失败时，第一步操作就是手动更新订阅。

Q6 什么是订阅转换（Subconverter）？什么时候需要用到？

订阅转换是将某种客户端格式的节点订阅，转换成另一种客户端所需格式的工具（例如将通用 V2Ray 链接转换为 Clash 的 YAML 规则配置）。现在绝大多数规范机场都已在后台直接提供了一键导入 Clash、Shadowrocket、Sing-box 等多种格式的原生链接，新手应优先使用机场官方自带的原生链接；只有在机场未提供特定软件配置或特定老旧客户端识别失败时，才需要使用受信任的订阅转换。

具体步骤 / 排查方法：
  1. 优先官方：尽量使用机场后台提供的原生客户端订阅链接。
  2. 注意安全：避免使用来源不明的公共第三方在线订阅转换，以防订阅 Token 泄露。
  3. 本地转换：进阶用户推荐使用本地开源 Subconverter 工具进行配置自定义。

02 订阅购买与套餐选择

Q7 新手第一次买机场订阅，建议选月付还是年付？

强烈建议新手第一次购买时坚持选择‘月付’。即便部分机场的年付打折力度很大，但作为新手，你需要先在晚高峰（20:00-23:00）实测该机场在你的本地宽带（电信/联通/移动）下的实际表现。月付仅需花费十几二十元，试错成本极低；如果体验良好，次月或第三个月再考虑周期更长的套餐也不迟。

具体步骤 / 排查方法：
  1. 规避风险：月付能彻底避免机场运营不善或跑路造成的资金沉没损失。
  2. 网络验证：不同宽带对不同线路表现差异大，月付是检验真实速度的最佳途径。
  3. 灵活调整：月付允许你随时根据当月流量使用情况升级或更换更适合的套餐。

Q8 100GB的机场套餐流量，一个人一个月够用吗？

对绝大多数个人用户来说，100GB/月的流量是完全充裕的。日常查阅技术文档、浏览海外资讯、使用社交聊天软件等，每月消耗通常不超过 15-30GB；即便是每天观看 1-2 小时的 1080P 高清视频，每月消耗也在 60-80GB 左右。只有在频繁下载超大文件、长时间挂机播放 4K 极清视频或多台设备共享时，才需要考虑 200GB 以上的大流量套餐。

具体步骤 / 排查方法：
  1. 轻度办公查资料：每月 20GB - 50GB 足够。
  2. 主流视频与社交：每月 100GB 刚好处于性价比黄金区间。
  3. 多设备与重度下载：建议选择 200GB-500GB 档位或不限时流量包。

Q9 机场套餐一个月大概多少钱算合理？太便宜的能买吗？

目前主流优质机场的月付价格普遍在 ¥15 - ¥30/月 之间，包含 80GB - 150GB 流量和专线/优质中转线路；轻量低频年付套餐通常在 ¥80 - ¥120/年 之间。如果遇到宣传‘5元包年’、‘9.9元永久无限流量’的机场，极大概率是超卖严重的劣质直连盘或随时准备卷款跑路的诈骗盘，新手切勿贪图极端便宜而踩坑。

具体步骤 / 排查方法：
  1. 合理区间：月付 15-30 元，线路与运维成本有基本保障。
  2. 警惕低价盘：低于正常服务器带宽成本的超低价往往伴随严重卡顿和跑路风险。
  3. 理性看待折扣：正规优惠码通常在 8-9 折区间，不会出现常年 1 折的非理性促销。

Q10 机场的不限时流量包和普通月付套餐有什么区别？哪个好？

普通月付套餐具有固定的自然月周期，每月到期后剩余流量清零并重置；而不限时流量包（又称按量计费/永久有效包）只要账号有效，购买的流量可以一直使用直到耗尽。如果你平时上网频率极低，仅偶尔查一次资料或作为备用线路，不限时流量包更划算；如果你每天都需要稳定上网办公或看视频，按月付套餐的单价通常更实惠。

具体步骤 / 排查方法：
  1. 低频备用：首选不限时流量包，一次购买可使用数月甚至一年。
  2. 高频日常：首选按月计费套餐，单位流量单价更低。
  3. 组合策略：主用一个优质月付套餐，搭配一个低价不限时包作为故障应急备用。

Q11 什么是节点倍率？为什么有时候流量消耗比实际下载的快？

节点倍率是指你在连接该节点时，产生的数据流量在后台计费时的乘数。例如：普通节点倍率为 1.0x，消耗 1GB 流量就扣除 1GB 套餐配额；低倍率节点（如 0.2x）消耗 1GB 实际只扣 0.2GB；而高倍率节点（如 2.0x 或 3.0x 极速专线）消耗 1GB 会扣除 2GB 或 3GB 配额。新手使用时务必留意节点名称中的倍率标注，避免在不知情下快速消耗完套餐流量。

具体步骤 / 排查方法：
  1. 查看名称：节点命名通常会包含 0.5x、1.0x、2.0x 等明显倍率标识。
  2. 日常选择：日常查资料或刷视频，建议优先选择 1.0x 或更低倍率的节点。
  3. 特定场景：只有在极度追求极端低延迟竞技或特定业务时，再切换高倍率节点。

Q12 买机场注册账号时，应该使用什么邮箱？需要实名吗？

正规机场绝不需要也不应该要求用户进行任何实名认证。为了保护个人隐私与账号安全，建议使用 ProtonMail、Gmail、Outlook 等国际常用邮箱进行注册，尽量避免使用带有个人真实姓名、身份证拼音或企鹅号纯数字前缀的国内个人邮箱。

具体步骤 / 排查方法：
  1. 隐私保护：注册专用海外邮箱，将机场服务与其他个人业务隔离。
  2. 密码安全：为不同机场设置独立的复杂密码，开启两步验证（如支持）。
  3. 谨防钓鱼：始终通过官方收藏夹或受信任的导航站点进入官网后台。

Q13 为什么注册链接里的邀请码不能当结算优惠码使用？

注册链接中的邀请码（Affiliate Code）是用来识别推荐来源的技术标识，通常在注册账户时系统会自动填入；而结算优惠码（Coupon Code）是服务商在促销活动中发布的打折凭证，必须在提交订单结算页面中的‘使用优惠码’输入框内手动输入并点击应用，才能核减订单金额。两者作用完全不同，不能混淆。

具体步骤 / 排查方法：
  1. 注册环节：点击注册链接直接完成账号创建，无需改动邀请参数。
  2. 选购套餐：在后台商店选择目标月付或年付周期，进入订单确认页。
  3. 应用优惠：在优惠码输入框中填入本站标注的专属红色优惠码，确认扣减金额后再付款。

03 客户端选择与全平台配置

Q14 目前主流的机场客户端有哪些？哪个最适合新手？

目前全平台主流的现代化代理客户端包括：Windows 平台首选 Clash Verge Rev 和 v2rayN；macOS 平台推荐 Clash Verge Rev 或 Sing-box；iOS/iPadOS 平台首选 Shadowrocket（小火箭）或 Sing-box；Android 安卓平台推荐 Clash Meta for Android、Clash Verge 移动版或 v2rayNG。新手推荐在电脑端使用界面直观、自带内核的 Clash Verge Rev，在苹果手机上使用操作极简的 Shadowrocket。

具体步骤 / 排查方法：
  1. Windows：推荐 Clash Verge Rev，中文界面清晰，分流规则成熟。
  2. macOS：推荐 Clash Verge Rev（支持 M1/M2/M3 及 Intel 芯片）。
  3. iOS：推荐 Shadowrocket（小火箭），支持扫码导入与自动节点测速。
  4. Android：推荐 Clash Meta (FlClash / NekoBox) 或 v2rayNG。

Q15 Clash Verge Rev 怎么导入机场订阅？具体操作步骤是什么？

在 Clash Verge Rev 中导入订阅只需三步：1. 打开软件，点击左侧菜单栏的‘订阅（Profiles）’；2. 在顶部的输入框中粘贴从机场后台复制的 Clash 订阅链接，点击右侧的‘导入（Import）’按钮；3. 导入成功后，在订阅卡片上单击选中，然后切换到左侧‘代理（Proxies）’页面选择节点，并在‘设置’中打开‘系统代理’开关即可。

具体步骤 / 排查方法：
  1. 复制链接：在机场后台点击‘复制 Clash 订阅’。
  2. 粘贴导入：在 Clash Verge Rev 的 Profiles 页面粘贴并点击 Import。
  3. 选节点与开启：在 Proxies 选香港/日本节点，在 Settings 开启 System Proxy。

Q16 Shadowrocket（小火箭）怎么导入机场订阅？

Shadowrocket 导入订阅有两种最简便的方法：第一种方法是‘一键导入’，在手机浏览器登录机场后台，点击‘导入到 Shadowrocket’，系统会自动唤醒小火箭并完成添加；第二种方法是手动添加，在小火箭首页右上角点击‘+’号，类型选择‘Subscribe（订阅）’，在 URL 处粘贴订阅链接并点击右上角‘保存’，小火箭会自动更新出全部节点列表。

具体步骤 / 排查方法：
  1. 一键唤醒：在手机端机场后台点击一键导入 Shadowrocket。
  2. 手动添加：点击右上角 + -> 类型选 Subscribe -> 粘贴 URL -> 保存。
  3. 启动连接：选择节点后，打开首页最上方的连接开关（初次需允许添加 VPN 配置）。

Q17 国内 App Store 搜不到 Shadowrocket 小火箭怎么办？

Shadowrocket（小火箭）未在中国大陆地区的 App Store 上架。要下载正版 Shadowrocket，你需要准备一个海外地区（如美区、日区、港区）的 Apple ID，登录 App Store 后搜索‘Shadowrocket’（图标为浅蓝底白色小火箭，开发者为 Shadow Launch Technology）进行购买和下载。切勿在非官方途径安装被二次打包篡改的盗版安装包。

具体步骤 / 排查方法：
  1. 准备账号：注册或获取一个海外地区的 Apple ID。
  2. 切换登录：打开 App Store，点击右上角头像退出当前账号，登录海外 Apple ID。
  3. 搜索下载：在商店搜索 Shadowrocket 并完成安装，下载完成后可换回原账号。

Q18 Windows 系统下使用 Clash Verge Rev，为什么建议安装 Service Mode？

Service Mode（服务模式）是 Clash Verge Rev 运行高级网络分流（如 TUN 虚拟网卡模式）的核心支持组件。安装服务模式后，客户端可以在系统底层直接接管所有软件的网络流量，包括那些不遵循系统代理设置的游戏、命令行终端和特殊办公应用，从而实现无死角分流并提升网络连接稳定性。

具体步骤 / 排查方法：
  1. 检查状态：在 Clash Verge Rev 左侧‘设置’中查看 Service Mode 状态。
  2. 一键安装：如果显示未激活，点击右侧的 Manage/Install 授权管理员权限安装。
  3. 启用 TUN：安装完成后即可随时自由开启 TUN Mode 获得最佳分流效果。

Q19 安卓手机使用机场订阅，有哪些注意事项？

在安卓设备上使用机场订阅，有两点特别需要注意：第一是‘省电策略与后台保活’，很多国产品牌安卓系统（MIUI、OriginOS、ColorOS 等）会强行在后台清理代理进程，需在系统设置中将客户端的电池优化设置为‘无限制’并锁定后台；第二是分流设置，建议开启‘绕过大陆地址/分流规则’，避免微信、国内地图等国内应用也走代理导致延迟变大或耗电异常。

具体步骤 / 排查方法：
  1. 锁定后台：在多任务界面长按代理客户端，加锁并允许后台自启动。
  2. 电池策略：在应用权限中关闭智能省电，允许不受限制的后台网络活动。
  3. 规则模式：客户端路由始终保持‘规则/Rule’模式，兼顾速度与省电。

Q20 Mac 苹果电脑怎么配置机场订阅？M系列芯片兼容吗？

Mac 电脑推荐使用原生适配 Apple Silicon（M1/M2/M3/M4）芯片的 Clash Verge Rev 或 Sing-box。下载安装时请注意选择后缀为 aarch64 或 arm64 的 DMG 安装包。安装完成后打开软件，同样通过 Profiles 界面导入订阅链接，在 Proxies 勾选节点，并在主界面打开‘系统代理’开关即可畅通使用。

具体步骤 / 排查方法：
  1. 下载对应架构：M系列芯片选择 arm64 架构包，Intel芯片选择 x64 架构包。
  2. 授权权限：初次打开若提示权限，在‘系统设置 -> 隐私与安全性’中点击仍要打开。
  3. 粘贴订阅：导入 Clash 订阅并开启系统代理，Safari 与 Chrome 即可秒开海外站点。

Q21 Windows 电脑休眠唤醒后，突然打不开任何网页怎么解决？

这是 Windows 系统代理机制在休眠恢复时常见的状态残留问题。解决非常快捷：首先在客户端中先关闭‘系统代理’开关，等待 2 秒再重新打开；如果依然打不开，按下 Win + I 打开 Windows 设置 -> 网络和 Internet -> 代理，手动检查‘使用代理服务器’的开关和端口是否与客户端一致，或者直接退出客户端软件重新启动即可恢复。

具体步骤 / 排查方法：
  1. 重启开关：在 Clash Verge 界面中将 System Proxy 关闭再重新开启。
  2. 检查系统代理：进入 Windows 设置检查代理开关，避免端口残留卡死。
  3. 彻底重开：在任务栏托盘右键彻底退出客户端并重新以管理员身份运行。

Q22 什么是 TUN 模式？它和普通系统代理有什么区别？

普通系统代理（System Proxy）是通过在操作系统中设置 HTTP/SOCKS5 代理端口来工作，只对主动遵从系统代理设置的软件（如浏览器）有效；而 TUN 模式是通过创建一个虚拟网卡，在操作系统最底层全面接管并按规则分流进出电脑的所有网络数据包。对于需要让命令行终端、游戏平台或未自带代理设置的软件走代理时，开启 TUN 模式最为彻底。

具体步骤 / 排查方法：
  1. 系统代理：适合绝大多数日常网页浏览、办公、看视频，开销小。
  2. TUN 模式：适合全盘流量代理接管、游戏联机加速、开发终端命令行等复杂场景。
  3. 切换提示：日常使用只需开启系统代理即可，有特殊全局需求再开启 TUN 模式。

04 线路与专线知识

Q23 机场直连、中转和专线有什么区别？新手怎么看懂？

这三种代表了数据出境的不同物理路径：直连是指你的电脑直接连接海外服务器，成本最低但晚高峰极其容易受骨干网拥堵和丢包影响；中转是指数据先发送到国内高带宽入口服务器，再由国内服务器转发至海外节点，网络波动显著减少；专线（如 IEPL/IPLC）则是租用完全不过公网防火墙的企业级内网跨境光纤，延迟最低、丢包极少，晚高峰稳定性最好。

具体步骤 / 排查方法：
  1. 直连线路：价格极低但晚高峰卡顿明显，不推荐主力使用。
  2. 中转线路：性价比高，绝大多数 15-25 元档机场采用的核心架构。
  3. 专线线路（IEPL/IPLC）：体验最平稳，晚高峰不卡顿，预算合适首选。

Q24 IEPL 和 IPLC 专线有什么区别？哪个更好？

IPLC（International Private Leased Circuit）是真正的国际私有租用物理线路，点对点硬性打通；IEPL（International Ethernet Private Line）是基于以太网技术的国际虚拟专线。对普通上网用户而言，两者的实际体验（低延迟、零公网丢包、不过防火墙）几乎完全一致，无需过度纠结两者的技术细微差异，只要是真专线而非虚假宣传的直连，晚高峰稳定性都远高于普通线路。

具体步骤 / 排查方法：
  1. 共同优势：均不经过公网国际出口，晚高峰网络抖动极小。
  2. 辨别真假：真专线在晚高峰测速丢包率极低且延迟曲线平直。
  3. 选购建议：20元左右能买到 IEPL/IPLC 专线套餐即可视为高性价比之选。

Q25 为什么机场在晚高峰（20:00-23:00）经常变慢或卡顿？

晚高峰变慢主要有三个原因：第一是全网国际出口总带宽在夜间迎来流量洪峰，普通公网线路发生严重拥堵和丢包；第二是部分低价小机场为了利润过度超卖，超出服务器承载上限；第三是本地运营商（电信/联通/移动）对不同线路的 QoS 限制。选用专线机场（如 IEPL）能有效绕过公网出口拥堵，从而在晚高峰保持相对平稳的速率。

具体步骤 / 排查方法：
  1. 避开公网拥堵：晚高峰优先选用 IEPL 专线或优质 BGP 中转节点。
  2. 切换空闲节点：晚高峰热门香港节点人数较多时，可临时切换到日本或新加坡节点。
  3. 理性认识：任何网络在晚高峰都会存在轻微波动，以能否流畅打开网页和视频为准。

Q26 节点延迟测试（Ping/ms）显示的几十毫秒代表什么？是真实下载速度吗？

延迟（Latency/Ping，单位为毫秒 ms）表示数据包从你电脑发送到节点并返回所需的时间，只代表响应快慢，不代表真实的下载带宽速度。比如 30ms 延迟意味着点击网页响应快，但如果节点带宽被占满，下载大文件依然可能很慢；反之 150ms 的美国节点虽然响应慢一点，但如果带宽充足，看 4K 视频同样可以跑满带宽。新手不要盲目只按延迟数字高低选节点。

具体步骤 / 排查方法：
  1. 延迟看响应：毫秒数越低，日常刷推、查文档、开网页感觉越灵敏。
  2. 带宽看速度：看高码率视频主要取决于节点出口的总可用带宽。
  3. 综合考量：选延迟在 30-100ms 之间且不丢包的节点体验最佳。

Q27 专线机场就一定 100% 永远不卡、永远不坏吗？

不是。任何网络服务都无法做到 100% 绝对不出现故障。专线线路同样可能会遇到上游骨干光缆维护、国内入口机房断电、机房网络遭受恶意攻击或服务商软件故障等情况。成熟的专线机场通常会配置多入口多出口的 BGP 容灾容错机制，即便某条专线维护，系统也会在后台自动切换至备用链路，从而最大程度减少断网时间。

具体步骤 / 排查方法：
  1. 正确预期：专线能解决 95% 以上的晚高峰公网拥堵，但并非神话。
  2. 容灾意识：保留一个不同服务商的月付或低价备用订阅，关键时刻不耽误事。
  3. 关注公告：遇到突发全网波动时先查看机场官方 Telegram 频道维护公告。

Q28 为什么很多机场不提供冷门国家节点？热门亚太节点够用吗？

香港、日本、新加坡、美国四个地区集中了全球 90% 以上的优质云服务器骨干带宽和绝大多数国际网站的边缘 CDN 节点。冷门国家（如阿根廷、土耳其、尼日利亚等）服务器成本极高、带宽极小且网络质量差，维护成本与实际需求不匹配。对绝大多数用户而言，香港、日本、新加坡、美国节点已完全满足日常 99.9% 的使用场景。

具体步骤 / 排查方法：
  1. 核心四地：香港（极速）、日本（稳健）、新加坡（兼顾）、美国（原生服务支持）。
  2. 冷门需求：若无特定跨区低价充值需求，无需执着于冷门小国节点。
  3. 稳定性优先：集中带宽保障核心亚太节点顺畅，是高品质机场的常见做法。

05 订阅故障排查与自救

Q29 机场订阅链接打不开、提示连接超时怎么办？

如果复制的订阅链接在导入时提示超时或打不开，通常有四个原因：1. 订阅域名遭到本地网络运营商拦截；2. 复制时多带了空格或前后字符缺失；3. 账号套餐已到期或流量已耗尽；4. 机场订阅服务器正在临时维护。排查方法：先登录机场官网确认套餐与流量是否正常，然后在用户中心尝试更换‘备用订阅域名’或‘订阅转换链接’重新导入。

具体步骤 / 排查方法：
  1. 第一步：登录官网确认账号状态，核实套餐是否有效、流量是否见底。
  2. 第二步：检查订阅链接完整性，确保前后没有多余空格或换行。
  3. 第三步：在用户中心切换‘备用订阅地址’或勾选‘转换格式’后重新复制。
  4. 第四步：尝试切换手机热点网络拉取订阅，排除本地宽带拦截。

Q30 客户端提示‘更新订阅失败（Connect Timeout / Fetch Error）’怎么解决？

更新订阅失败通常是因为客户端拉取订阅时的请求被本地网络阻断。解决办法：如果当前已经有可用节点，可以先打开客户端连接现有节点，然后再点击‘更新订阅’（即节点更新走代理通道）；如果所有节点都已经失效，可在客户端订阅设置中将订阅链接的域名部分替换为机场提供的备用防污染域名，或者连接手机 4G/5G 热点后再点击更新。

具体步骤 / 排查方法：
  1. 借梯更新：开启现有连接代理，再点击更新订阅。
  2. 切换网络：断开家庭 WiFi，用手机热点临时更新。
  3. 备用链接：在机场后台重新复制一条新的备用订阅地址粘贴替换。

Q31 机场节点全部超时（显示 -1ms 或 Timeout）但国内网页正常，是什么原因？

节点全部变红超时通常是由以下原因引起的：1. 电脑系统本地时间与标准北京时间偏差超过 1 分钟（导致 TLS 加密握手失败，最常见！）；2. 机场套餐欠费或流量耗尽；3. 机场全部服务器发生集中故障或入口迁移；4. 防火墙软件误杀了代理内核进程。

具体步骤 / 排查方法：
  1. 第一步：同步系统时间（打开 Windows/Mac 设置，点击立即同步网络时间）。
  2. 第二步：登录后台查看套餐余额与剩余流量。
  3. 第三步：手动点击更新一次订阅，获取最新服务器 IP。
  4. 第四步：彻底重启代理客户端软件。

Q32 排查节点不可用的‘黄金四步法’是什么？

当遇到无法连接时，按照以下顺序排查可以在 2 分钟内解决 90% 的问题： 1. 【对时】：检查并同步系统时间到北京标准时间； 2. 【查量】：登录机场官网后台，确认套餐未过期、流量未用完； 3. 【更新】：在客户端中右键点击订阅卡片，执行‘更新/刷新订阅’； 4. 【重置】：关闭客户端系统代理，彻底退出软件后重新以管理员身份打开。

具体步骤 / 排查方法：
  1. 时间同步：误差超过 60 秒会导致所有节点握手失败。
  2. 流量核验：确认账户状态为 Active。
  3. 订阅重拉：更新节点获取最新可用入口。
  4. 进程重启：清理残留网络端口占用。

Q33 开启代理后，微信、QQ 或国内网银打不开或提示网络异常怎么办？

这是因为客户端被错误地设置为了‘全局模式（Global）’，导致所有国内应用的流量也被强行发送到了海外节点。解决方法：在客户端的代理模式中，将‘Global（全局）’切换为‘Rule（规则模式）’或‘Direct（直连模式）’。在规则模式下，客户端会内置智能分流规则列表，让国内软件自动直连本地网络，既不消耗代理流量，也不会影响国内软件正常使用。

具体步骤 / 排查方法：
  1. 检查模式：将模式从 Global 改为 Rule / 规则分流。
  2. 更新规则：在客户端配置中确保预设规则集为最新版本。
  3. 应用分流：遇到特殊政企网银，可在客户端中将该域名手动添加到 Direct 直连名单。

Q34 订阅链接在微信或 QQ 里发送给朋友后为什么会失效？

微信和 QQ 内置的安全检测爬虫会对在聊天中发送的未知 URL 进行后台静默抓取和安全扫描。这种高频自动化访问容易触发机场服务器的防爬虫风控机制，导致该订阅链接或当前 IP 被临时封禁，或者链接在转发中被聊天软件自动加上后缀转义字符导致损坏。切勿在微信/QQ 中直接明文传输订阅链接，如需分享请使用密码压缩包或加密通讯工具。

具体步骤 / 排查方法：
  1. 切勿明文转发：避免在微信、QQ、抖音等国内社交平台直接发送订阅链接。
  2. 重置订阅：如果不小心明文发送导致被封，在机场后台点击‘重置订阅 Token’。
  3. 安全传输：使用密码保护的文本或安全工具进行设备间传输。

Q35 电脑和手机可以同时使用同一个机场订阅吗？设备数怎么算？

绝大多数机场都允许同一个订阅在你的多台个人设备上（如电脑、手机、平板）同时导入和使用。关于‘同时在线设备数’的限制，通常是指在同一时间点‘同时产生网络连接数据’的公网 IP 数量或客户端连接数。个人正常在手机和电脑上同时开着代理，通常都在套餐允许的 2-5 台设备范围内，完全不影响使用。

具体步骤 / 排查方法：
  1. 多端配置：同一条订阅链接可以复制导入到手机小火箭和电脑 Clash 中。
  2. 严禁外传：切勿将个人订阅公开发布给多位朋友使用，否则超标会被系统自动封号。
  3. 升级配额：多家庭成员共用时，建议在后台升级为允许多连接的家庭或团队套餐。

Q36 订阅链接被泄露给别人了怎么办？会不会被盗刷流量？

一旦别人拿到你的订阅链接，就可以将其导入他们自己的客户端中使用你的套餐流量，甚至可能因为多人同时使用触发系统防超卖机制导致账号被封。解决办法非常简单：立即登录机场官网用户中心，找到‘重置订阅链接’或‘Reset Token’按钮并点击，旧链接会瞬间永久失效，随后复制生成的新订阅链接重新导入你的设备即可。

具体步骤 / 排查方法：
  1. 立即重置：在用户中心点击‘重置订阅信息’让旧 Token 立即作废。
  2. 重新复制：获取生成的一条全新订阅链接。
  3. 更新设备：将新链接重新填入自己的客户端并更新。

Q37 什么是 DNS 污染？机场客户端是如何解决的？

DNS 污染是指当你在国内网络查询海外网站域名对应的 IP 地址时，被恶意返回了一个虚假错误的 IP 地址，导致你无法打开目标网站。现代代理客户端（如 Clash、Sing-box、Shadowrocket）内置了智能 DNS 模块和 Fake-IP 机制，通过将海外域名的 DNS 解析交由海外远端节点代为完成，彻底绕过了本地网络对域名的污染劫持。

具体步骤 / 排查方法：
  1. 远离污染：开启规则模式后，海外域名的解析全部由远端代理节点处理。
  2. 保持默认：新手建议保持客户端默认的 Fake-IP / Redir-Host 设置，不要随意修改高级 DNS。
  3. 防泄漏：配合客户端内置规则即可确保上网请求安全与隐私。

Q38 开启 TUN 模式后电脑无法打开任何网页，关闭后恢复，怎么处理？

TUN 模式异常通常是因为系统的虚拟网卡驱动损坏、旧版冲突、或者与其他杀毒安全软件的底层网络拦截发生冲突。解决方法：1. 在 Clash Verge Rev 中先卸载服务模式（Service Mode），重启电脑后重新安装最新版服务模式；2. 检查电脑上是否安装了管家类拦截软件，暂时关闭网络防火墙；3. 若依然异常，日常使用只需保持‘系统代理’开关打开即可，不影响绝大多数日常使用。

具体步骤 / 排查方法：
  1. 卸载重装：在设置中重新安装 Service Mode 驱动。
  2. 重启系统：重启 Windows 网络堆栈。
  3. 降级使用：关闭 TUN 模式，仅使用稳定的系统代理模式。

06 避坑指南与防跑路

Q39 怎么买机场不容易踩坑？新手四大核心原则是什么？

新手选购机场只需牢记四大黄金原则： 1. 【首选月付】：前两个月坚决不买半年付或年付，先花十几二十元试水真实体验； 2. 【远离极端低价】：警惕几元包年、几十元永久无限流量等超卖陷阱； 3. 【认准专线中转】：优先选择标明 IEPL/IPLC 专线或 BGP 多线中转的成熟品牌； 4. 【检查服务社群】：查看机场是否有活跃的 Telegram 公告群、交流群或工单响应机制。

具体步骤 / 排查方法：
  1. 原则一：月付先行，满意再续。
  2. 原则二：尊重服务器成本，远离白菜价套路盘。
  3. 原则三：选专线或正规中转，晚高峰少受罪。
  4. 原则四：看有无真实群组交流和更新公告。

Q40 机场跑路前通常有哪些反常征兆？新手怎么提前识别？

机场跑路前往往有非常典型的反常行为： 1. 【无底线超大折扣促销】：突然推出前所未有的‘3折买3年’、‘99元永久无限流量’； 2. 【节点大面积故障长期不修】：主要节点红了一周以上，管理人员找借口推脱不换服务器； 3. 【禁言或关闭官方交流群】：将原本公开讨论的 Telegram 群组转为全员禁言或直接解散； 4. 【工单长期无人回复】：提交工单数天无实质反馈。遇到上述两种情况，立即停止续费并及时寻找备用。

具体步骤 / 排查方法：
  1. 异常打折：突然大量销售长期巨额优惠套餐（敛财跑路常见套路）。
  2. 群组异常：禁言群聊、关闭工单系统。
  3. 线路瘫痪：长达数周不修复核心节点。

Q41 网上很多‘永久免费梯子’或‘免费机场订阅’安全吗？

天下没有免费的午餐。维持海外服务器和国际跨境专线需要高昂的硬件与带宽成本。所谓的‘永久免费梯子’通常有三种盈利途径：1. 在客户端内强制植入大量恶意弹窗广告；2. 收集记录你的浏览历史、明文数据和个人隐私并转卖变现；3. 作为黑客肉鸡节点劫持流量。为了个人数据资产安全，切勿在免费梯子环境下登录网银、邮箱或重要社交账号。

具体步骤 / 排查方法：
  1. 安全隐患：免费节点存在严重的中间人监听和数据窃取风险。
  2. 速度极慢：免费节点数百人抢用极小带宽，卡顿严重无法日常使用。
  3. 正确姿势：选择十几元合规月付付费机场，保障数据安全与流畅体验。

Q42 如果遇到机场突然跑路失联，新手应该怎么妥善处理？

首先保持冷静，如果你坚持了‘月付’原则，实际经济损失仅为十几元的一顿快餐钱。第一步：在客户端中删除或禁用该失效订阅，避免客户端频繁重试占用 CPU；第二步：进入受信任的导航测评站点，挑选另一家支持月付且口碑良好的成熟机场；第三步：注册新账号并重新导入订阅，即可在 5 分钟内完全恢复上网。

具体步骤 / 排查方法：
  1. 清理旧订阅：在客户端 Profiles 中删除失效订阅配置。
  2. 快速迁移：挑选本站推荐的稳定月付机场进行备用过渡。
  3. 吸取经验：牢记单月付费原则，绝不大额预付长期费用。

Q43 为什么不同宽带（电信/联通/移动）使用同一机场体验可能差异很大？

因为国内三大运营商的国际出口路由和国内骨干网互联互通机制不同。通常情况下：中国电信出境带宽大但普通公网晚高峰丢包率偏高（需要 CN2 GIA 或专线）；中国联通国际出口阻力较小，访问日本、欧洲体验通常较好；中国移动国际带宽大但墙内省际穿透调度复杂。正规机场采用 BGP 多线入口，可以让三大运营商用户分别接入对应最优服务器，从而抹平运营商差异。

具体步骤 / 排查方法：
  1. 电信用户：优先选择 BGP 入口或 IEPL 内网专线节点。
  2. 联通用户：访问日本、新加坡中转节点表现普遍优秀。
  3. 移动用户：选择有多省 BGP 接入的机场，避免跨省调度延迟。

Q44 买机场付款时一般支持哪些方式？会不会泄露个人银行信息？

目前绝大多数面向大众的机场平台均接入了第三方发卡或支付网关，支持常见的支付宝、微信支付或加密货币（USDT）结算。付款过程跳转至正规支付通道完成，机场服务器端无法获取你的银行卡号或支付密码。新手在支付时注意确认实际扣款金额与套餐标价一致即可。

具体步骤 / 排查方法：
  1. 主流支付：支持常见便捷手机扫码支付。
  2. 信息隔离：支付通道由第三方承兑，机场后台仅接收支付成功状态回执。
  3. 小额试水：首次支付选择月付小额，安全可控。

Q45 买机场后发现订阅无法导入，或者速度极慢，应该找谁解决？

首先在机场官网后台找到‘提交工单（Ticket）’或‘在线客服’功能，详细描述你的问题（附上客户端类型、报错截图、使用的网络运营商等），正规机场运维会在数小时内回复排查；同时可在机场官方 Telegram 交流群中搜索历史发言或向群管询问。在提问前，先按照本站排障四步法同步时间和更新订阅，很多时候能自己立即解决。

具体步骤 / 排查方法：
  1. 先自查：同步电脑时间 -> 确认套餐有量 -> 换备用订阅重新拉取。
  2. 提交工单：提供具体报错文字与客户端版本。
  3. 加入社群：通过用户中心提供的官方 TG 链接进群交流。

Q46 机场节点名称里带的‘原生 IP’或‘住宅 IP’是什么意思？重要吗？

‘原生 IP’是指服务器 IP 地址在数据库中的注册注册地与机房实际物理所在地完全一致；‘住宅 IP’是指由当地家庭宽带运营商（如 AT&T、Comcast）分配给居民的真实住宅网络 IP。对于普通用户日常浏览网页、查阅论文、发邮件而言，普通优质机房 IP 和原生 IP 在速度上没有任何差别，无需额外花高价追求噱头。

具体步骤 / 排查方法：
  1. 普通用途：标准机房 IP 速度快、带宽大，完全满足日常需求。
  2. 特定用途：部分严控机房 IP 的海外特定服务才需要原生 IP 支持。
  3. 务实选择：以节点实际连通率和晚高峰流畅度为核心考量指标。

Q47 为什么有的机场网站经常更换网址和登录域名？

因为机场的官方网站前端页面经常会受到公共防火墙的域名污染或阻断，导致国内用户直接访问官网困难。为了让用户能够正常登录后台续费、下载客户端和获取订阅，机场会准备多个轮换的备用发布页或通过 Telegram 频道发布最新无污染官网入口。这属于行业常规运维行为，只要用户中心数据和节点订阅正常，不必过于惊慌。

具体步骤 / 排查方法：
  1. 关注官方群：加入机场官方 Telegram 频道，随时获取最新登录地址。
  2. 保存永久邮箱：部分机场提供向特定邮箱发邮件自动获取最新网址的功能。
  3. 订阅不受影响：官网域名轮换通常不影响已经导入客户端的节点正常使用。

Q48 什么是‘备用机场’？为什么老手都建议准备两条不同机场的订阅？

‘备用机场’是指在你主力使用的主机场之外，额外购买或保留一个低成本的备用订阅（例如一个几十元的低价年付套餐，或一个不过期的不限时按量流量包）。由于国际网络可能遇到突发光缆中断、敏感时期临时管控或服务商机房维护，一旦主力机场断连，备用订阅可以在 5 秒内无缝切换，确保你的重要工作和学习不掉线。

具体步骤 / 排查方法：
  1. 主力方案：选择高品质 IEPL 专线月付套餐（¥20-¥25/月），日常主力使用。
  2. 备用方案：选择百元年付或不限时流量包，平时待命，故障时一键切换。
  3. 双保险配置：在 Clash 或小火箭中同时导入两个订阅，随时按需挑选节点。

Q49 在公共场所 WiFi（如咖啡厅、机场候机厅）使用机场订阅安全吗？

非常安全，甚至比不使用代理更安全。公共免费 WiFi 通常没有加密保护，容易被黑客搭建伪造热点窃听明文数据。开启机场代理后，你的所有网络流量在离开设备前就已经被代理协议（如 Shadowsocks、TLS）进行了端到端加密，即便公共 WiFi 存在嗅探攻击，黑客也只能看到一串无法解密的加密数据包，无法获取你的真实浏览内容。

具体步骤 / 排查方法：
  1. 加密保护：代理隧道能有效防止公共 WiFi 环境下的数据抓包。
  2. 连接先开：连接公共 WiFi 成功后，立即打开客户端代理开关。
  3. 防止假热点：依然建议不要在非加密网页中输入敏感账户密码。

Q50 第一次买机场的新手完整清单有哪些？

新手首次入坑，照着这张清单操作即可零踩坑： 1. 【选设备软件】：Windows 下装 Clash Verge Rev，苹果手机准备海外账号下 Shadowrocket，安卓手机装 Clash Meta； 2. 【买月付试水】：选择 ¥20 左右的专线/中转月付套餐（如梯子云或暮光加速），填入优惠码； 3. 【导入订阅】：在后台复制订阅链接，粘贴至客户端拉取节点； 4. 【校准时间】：同步设备时间，选择延迟较低的香港或日本节点； 5. 【开启代理】：开启规则模式（Rule）和系统代理，开始流畅上网。

具体步骤 / 排查方法：
  1. 第一步：客户端准备到位。
  2. 第二步：小额月付完成购买并核销优惠码。
  3. 第三步：导入订阅并验证节点连通性。
